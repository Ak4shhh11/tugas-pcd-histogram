ANALISIS HISTOGRAM PLAT NOMOR - OPENCV

1. Masukkan gambar ke folder images dengan nama:
   plat_asli.jpg
   plat_terang.jpg
   plat_gelap.jpg

2. Buka terminal pada folder proyek.
3. Aktifkan venv jika sudah dibuat:
   .venv\Scripts\activate.bat

4. Instal pustaka:
   python -m pip install -r requirements.txt

5. Jalankan:
   python main.py

Navigasi jendela:
   1 = Plat asli
   2 = Plat terang
   3 = Plat gelap
   A = Simpan tampilan yang sedang terbuka
   Q atau ESC = Keluar

Hasil akan tersimpan pada folder output.
